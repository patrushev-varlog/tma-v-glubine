# Вин-рейт по уровням и веткам на «Испытании»

Финальный прогон после настройки (октябрь 2026). Обе стороны ведёт ИИ прототипа, по 200 боёв на строку, без Велиора. Цель: 30–50% без тёмных даров и 50–70% с ними. Погрешность при 200 боях около ±4 п.п.

## С экипировкой: волшебник (октябрь 2026)

Отряд носит гарантированный набор своего уровня (`Items.KITS`, каталог: design/equipment-catalog.md в файлах проекта). С ним волшебник на 3–5 уровнях выигрывал 59–93%, поэтому хиты врагов подняты: бой 3 уровня +12%, 4-го +25%, 5-го +40% (`boost` в `Content.BATTLES`). 1–2 уровни не менялись: набор 2-го уровня (+1 к одному предмету) оставил их в рамке.

| Ветка | Ур. 1 | Ур. 2 | Ур. 3 | Ур. 4 | Ур. 5 |
|---|---|---|---|---|---|
| — | 35% / 66% |  |  |  |  |
| Воплотитель |  | 46% / 70% | 48% / 69% | 43% / 65% | 43% / 65% |
| Сковыватель |  | 46% / 69% | 33% / 61% | 41% / 54% | 44% / 56% |

Цифры обновлены после исправления багов боя (B1, 12.10.2026), по 200 боёв; до исправлений по тем же сидам было в пределах ±2 п.п. (Сковыватель 3 уровня 32% / 59%). Первый замер: 3 уровень по 400 боёв. Хиты врагов одной ручкой не уравнивают ветки: Сковыватель 3 уровня на нижней границе, Воплотитель на верхней.

**Всё найденное сверх бюджета** (`gear=full`: скрытые легендарки охот, бирка Гаррета, колокол Ирены, кинжал Велиора) прибавляет волшебнику 10–30 п.п. без даров: 2 уровень 56–57%, 3-й 45–79% (замер при +15% хитов врагов), 4-й 71–77%, 5-й 57–64%. Это больше задуманных 5–10 п.п.

**Остальные классы** с экипировкой и новыми хитами врагов ещё не прогонялись: таблица ниже снята без экипировки и до усиления врагов.

Повторить: `godot --headless --path prototypes/combat -s res://tools/simulate.gd -- class=wizard gear=kit` (`gear=none` — без экипировки, `gear=full` — с найденным).

В ячейке: без тёмных даров / с ними.

Что сдвинули исправления (сравнение с прогоном тех же настроек до них):
- Волшебник — в пределах ±2 п.п., рамка цели не задета.
- Воин: 2–3 уровни +4…+11 п.п. (больше хитов), 5 уровень −8…−14 п.п. На «Испытании» враги ценят хрупкие цели; воин с 37 хитами перестал быть приманкой, и удары уходят спутникам.
- Плут-Убийца: +3…+4 п.п. (прятки теперь защищают). Остальные классы — в пределах ±3 п.п.

Воин, плут и жрец с экипировкой выше рамки почти везде, и так было и до исправлений: под набор подгонялся только волшебник. Компенсацию хитов воина и подгонку остальных классов под экипировку делает поток B5 (экипировка в балансе); правка одних хитов воина её не заменяет.

Повторить: `godot --headless --path prototypes/combat -s res://tools/simulate.gd -- class=fighter` (по умолчанию все уровни, ветки и `gear=kit`).
