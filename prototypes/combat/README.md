# Серый прототип боя

Бой 3 пролога («колонна у ворот рудника») из фигур и кубиков: правила SRD 5.2 в урезанном виде, изометрическое поле 18×14 со стеной рудника, воротами и коридорами, ИИ врагов, интерфейс для мыши и пальца. Цель — проверить на 3–5 людях, весело ли играть, до работы над графикой (см. `DESIGN.md`, порядок разработки, шаг 1).

## Как запустить

1. Скачать Godot **4.7.2 standard** (не .NET) с godotengine.org. На Mac с M1 Pro подходит универсальная сборка для macOS.
2. В менеджере проектов Godot: Import → выбрать `prototypes/combat/project.godot`.
3. Запустить (F5 или кнопка ▶).

Без редактора, из терминала:

```sh
godot --path prototypes/combat
```

## Что в бою

- Отряд: герой (Воин, Плут, Жрец или Волшебник), Ирена и Гаррет; Велиор — по галочке в меню.
- Враги на «Испытании»: старший надсмотрщик, два надсмотрщика, два зомби, два скелета-лучника. Они бьют хрупких и раненых и стараются не подставляться под атаки при уходе. На «Истории» на одного надсмотрщика и одного лучника меньше.
- Стрелять и колдовать можно только по линии обзора: стены и телеги её перекрывают, фигуры нет. Лук и большинство заклинаний бьют на 8 клеток, «Огненный снаряд» и «Волшебная стрела» на 10.
- Правила: d20 против КД, 1 и 20 на кубике, преимущество и помеха, критический удар удваивает кости, спасброски против СЛ 13, атаки при уходе (единственная реакция), Отход, сбивание с ног, скрытая атака, ячейки и способности «на день».
- Герои при 0 хитов выбывают и поднимаются лечением; враги погибают.
- Тёмные дары у героя: не больше трёх за бой, каждый даёт +2 Тьмы. Счётчик Тьмы виден сверху только в прототипе.
- Режимы: «История» (меньше врагов, их урон ×0,6, можно переиграть с начала хода) и «Испытание».
- Сохранение в начале каждого хода героя; «Продолжить с начала последнего хода» в меню возвращает туда же с тем же броском кубиков.

## Управление

| Действие | Мышь | Палец |
|---|---|---|
| Прогноз (шанс, урон, путь) | клик по клетке | тап |
| Подтвердить | второй клик по той же клетке | второй тап |
| Сдвинуть камеру | перетащить | провести пальцем |
| Масштаб | колесо | щипок |
| Показать героя на поле | клик по портрету | тап по портрету |

Внизу кнопки способностей: выбрать способность, тапнуть цель (или самого героя для способностей «на себя»), тапнуть ещё раз для применения. «Движение и атака» возвращает к обычному режиму; тап по врагу рядом — атака, по дальнему — подход и атака.

## Что проверять на людях

- Понятно ли без объяснений, куда можно идти и кого бить; хватает ли прогноза перед вторым тапом.
- Не раздражает ли двойной тап на ПК и на телефоне.
- Сколько длится бой и в какой момент становится скучно.
- Берут ли тёмные дары и почему; заметна ли цена.
- Кем интереснее играть и кто из спутников кажется лишним.

## Тесты и симуляция

```sh
godot --headless --path prototypes/combat --import            # один раз, чтобы Godot зарегистрировал классы
godot --headless --path prototypes/combat -s res://tests/run_tests.gd   # правила: 44 проверки
godot --headless --path prototypes/combat -s res://tests/ui_smoke.gd    # целый бой через интерфейс
godot --headless --path prototypes/combat -s res://tools/simulate.gd    # таблица баланса, несколько минут
```

Симуляция ведёт обе стороны грубым ИИ, поэтому её проценты побед — ориентир для сравнения вариантов, а не оценка живого игрока.

## Устройство

- `scripts/rules/` — правила без графики: кубики, участник, содержимое (классы, спутники, враги, способности, сценарий), бой, ИИ, симулятор.
- `scripts/view/board_view.gd` — рисует поле, подсветку и фигуры.
- `scripts/main.gd` — меню, интерфейс, ввод и камера.
- `tests/`, `tools/` — проверки и симуляция.
